# ForgeMart

A deliberately realistic full-stack commerce service. This repository is the
demonstration target for FORGE — it is intentionally small enough to reason
about end-to-end while exposing a real, multi-file reliability defect.

## Layout

```
apps/
  api/       HTTP application (routes + payment webhook dispatch)
  worker/    background notification worker
  web/       web client helpers (catalog browsing)
packages/
  shared/    logging, errors, runtime config, shared types
  database/  in-memory stores (sessions, orders)
  payments/  payment lock, confirmation, checkout orchestration
  auth/      token signing + request middleware
tests/
  unit/        fast unit coverage
  regression/  regression coverage generated by FORGE
```

## Development

```bash
npm install
npm run typecheck     # TypeScript strict
npm test              # Vitest
```
